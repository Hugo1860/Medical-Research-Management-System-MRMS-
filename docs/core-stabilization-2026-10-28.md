## 重复执行

```bash
# 临时 PostgreSQL：无宿主端口、无业务卷；执行完自动清理本次资源
./deploy/run-isolated-regressions.sh

# 只构建 publish/linux-x64；不启动、不重启任何业务服务
./deploy/build-local-release.sh
./deploy/verify-publish-parity.sh
```

需要 Docker、Python 3、Node/pnpm、timeout；默认从官方 .NET SDK/NuGet 获取依赖。网络受限时可在被忽略的 `deploy/nuget-local/` 放入官方 nupkg 缓存，设置 `NUGET_REMOTE_SOURCE=''` 使用离线包源；`SDK_IMAGE` 可指定已缓存 SDK 镜像。离线缓存须与 SDK 所需版本匹配。

隔离脚本清除继承的数据库连接变量，固定临时库名/用户，并关闭菜单 HTTP 探测。测试使用合成身份和数据，覆盖生产 Controller/Worker/SQL，但不执行真实 Keycloak 登录或访问供应商。

## 剩余验收与建设事项

1. 在部署候选环境完成真实角色登录、权限拒绝、业务提交与持久记录的 UAT；本轮单元/数据库行为回归不能代替这些证据。
2. HR/财务等外部集成仍需真实供应商端点与凭据，并验证成功回执、重试和对账；签章、档案和消息发送仍有未实现的适配端，不能标记真实集成完成。
3. 字段/流程策略的配置界面不能代表全业务执行；需单独补齐策略消费和跨角色验证。
4. 历史数据完整性问题仍需业务核对；本轮不自动更改或清除历史异常数据。
5. 生产环境需按备份、迁移、发布、角色 UAT 的顺序实施，并配置计划书原件卷。当前只生成本地离线候选产物。历史公开静态目录里的原件副本需要在受控恢复与备份核验后由运维归档并撤销公开访问；本轮不删除旧件。
6. 现有前端测试中仍有偏配置/表达式的轻量用例；本轮新增行为回归提高重点路径可信度，但尚未形成全系统端到端覆盖。
