# 人员进修管理 P0

迁移 `092_continuing_education_p0.sql` 已应用到本地运行库，当前 `系统迁移版本` 为 92。迁移创建年度计划、进修申请、流程配置/节点、审批待办、进修通知和进修操作审计表，并预置“科主任审批→分管领导审批→科研管理员备案”生效版本。

控制器 `FurtherEducationController` 同时提供 `/FurtherEducation/*` 和 `/ContinuingEducation/*` 路由。主要接口如下：

- 年度计划：`查询年度计划`、`保存年度计划`、`发布年度计划`
- 申请：`查询进修申请`、`保存进修申请`、`提交进修申请`、`撤回进修申请`
- 审批与预算：`查询进修待办`、`审批进修申请`、`锁定进修预算`、`释放进修预算`
- 配置：`查询流程模板`、`保存流程配置`、`发布流程配置`
- 查询：`查询预算台账`、`查询审计记录`、`查询进修通知`、`标记进修通知已读`

提交、审批、撤回和预算操作在同一 PostgreSQL 事务内完成。计划关联申请提交时使用行锁校验名额和预算余额，审批退回/撤回释放占用；申请和待办通知均写入业务审计。真实 HR、财务回写和移动消息网关不在 P0 范围内。
